## 🌌 About the Project

**A.B.I.R | Beyond Ordinary** is my personal developer portfolio — a space where I showcase my projects, experiments, skills, and ideas.

The website is designed around a futuristic, minimal, and immersive aesthetic while keeping the experience fast, responsive, and easy to navigate.

> **Beyond Ordinary** isn't just a portfolio. It's a digital representation of what I build, what I learn, and where I'm heading.

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser and a code editor such as Visual Studio Code.

For the best local development experience, using the **Live Server** extension in VS Code is recommended.

### Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### Enter the Project Directory

```bash
cd YOUR-REPOSITORY
```

### Run Locally

Open the project in Visual Studio Code and launch `index.html` using Live Server.

The website should then be available through your local development server.

## 🧩 Components

The website uses reusable components for commonly shared sections.

### Header

Contains the main navigation and primary call-to-action.

### Topbar

Provides the primary navigation experience and branding.

### Footer

Contains supporting navigation, social links, copyright information, and other footer content.

These components are loaded dynamically through JavaScript rather than being duplicated across every page.
